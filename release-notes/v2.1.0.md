## What's new

- **Search your scenery list.** The **X-Plane Custom Scenery** page now has a search box above the list. Type part of a package's name or folder, such as *kden* or *D:\Ortho4XP*, and only the packages that match are shown. Capitals don't matter, and a folder can be typed with \ or /. On the right, the page counts the packages: all of them, or how many match, such as *3 of 1,623 packages*. **Esc** or the **×** in the box shows the whole list again.
- **Show in list.** While you search, each package that matches has a **Show in list** button. It clears the search, scrolls to the package and marks it with a coloured border, so you can drag it to a new place.

## Good to know

- While you search, the switches work as usual, but packages can't be dragged: between two packages that match, many others may be hidden. Use **Show in list** first, or clear the search.
- The search stays when the list is read again, after **Refresh**, Start or Stop.
- As before, the list can be changed only while OrthoStreamXP is stopped. Searching works at any time.
- Nothing changes for your packages or settings with the update.
